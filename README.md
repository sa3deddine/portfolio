# Portfolio — Saad Eddine Laouina

React + Vite. Ton contenu est dans `src/data.js`, le style dans `src/index.css`.

## Lancer en local
```
npm install
npm run dev
```

## Héberger gratuitement sur Vercel
1. Crée un dépôt GitHub et pousse ce dossier (`git init`, `git add .`, `git commit`, `git push`).
2. Sur vercel.com, connecte-toi avec GitHub, clique **Add New → Project** et choisis le dépôt.
3. Vercel détecte Vite tout seul (Build: `npm run build`, Output: `dist`). Clique **Deploy**.

Sans GitHub : `npm i -g vercel` puis `vercel` dans ce dossier.
